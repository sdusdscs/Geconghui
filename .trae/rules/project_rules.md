# 项目规则

## 命名规范

- 所有 JavaScript 变量名称以 `gch_` 开头
- 所有 CSS 类名以 `gch_` 开头
- 所有 HTML id 名称以 `gch_` 开头

## HTML 注释要求

每个 HTML 页面中必须包含以下格式的注释：

```html
<!-- 姓名：葛聪慧，日期：功能名称 -->
```

- 日期使用当前实际日期（如 2026-10-08）
- 功能名称用简短中文描述该页面功能

## 技术栈

- 使用原生 HTML、CSS、JavaScript 实现，不使用第三方库和 CDN
- 图标使用 `font/` 目录下的 iconfont 图标
- 获取服务器端数据使用 `fetch` API

## 代码风格

- 不添加注释（除非用户明确要求）
- CSS 类名和 id 名使用小写字母和下划线连接（snake_case）
