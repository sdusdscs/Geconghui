Web 前端长度单位展示

系统展示 CSS 中常用的长度单位：绝对单位、相对单位、视口单位与百分比单位，并给出换算关系与直观对比。

一、绝对单位（换算表）

单位 含义 与 px 的换算 常见用途
px像素1px = 1px屏幕元素最常用
pt磅1pt = 96/72 px ≈ 1.333px打印样式
pc派卡1pc = 12pt = 16px打印样式
in英寸1in = 96px打印样式
cm厘米1cm = 96/2.54 px ≈ 37.8px打印样式
mm毫米1mm = 96/25.4 px ≈ 3.78px打印样式
标准换算：1in = 96px = 72pt = 6pc；1cm ≈ 37.8px。屏幕上以 px 为主，物理单位主要用于 @media print。

三、相对单位：em / rem / ch / ex

父元素 font-size = 20px
子元素 1.5em → 相对父元素 = 30px
1.2rem → 相对根元素 html（默认 16px）= 19.2px
ch 示例（等宽字体）：0000 的每个 0 宽度即 1ch，用于限制每行字符数
单位 参照对象 说明
em父元素 font-size嵌套使用会层层叠加
rem根元素 html 的 font-size不受父级影响，适合整体缩放
ch当前字体数字 0 的宽度常用于文本行宽限制
ex当前字体 x 的高度与小写字母高度相关
em 相对父元素、rem 相对根元素：修改 html 的 font-size 即可整站缩放。

四、视口单位：vw / vh / vmin / vmax

40vw（视口宽度的 40%）
12vh（视口高度的 12%）
18vmin
取宽高中较短者
30vmax × 10vmax
取宽高中较长者
单位 参照对象 取值
vw视口宽度1vw = 视口宽度的 1%
vh视口高度1vh = 视口高度的 1%
vmin视口宽高较小值min(1vw, 1vh)
vmax视口宽高较大值max(1vw, 1vh)
拖动浏览器窗口大小，以上盒子会随视口实时变化，适合做全屏与自适应布局。

五、百分比 % 与自动单位

width: 60%（相对父容器宽度）
单位 参照对象 常见用途
%父元素对应属性流式布局、宽度/间距自适应
auto由浏览器计算外边距居中、剩余空间分配
% 相对父元素的同名属性：width 相对父宽，height 相对父高，margin 相对父宽。
