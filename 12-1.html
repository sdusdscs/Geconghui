一页看懂 CSS 变量

在 :root 中定义 --变量名，用 var() 调用；改一处，处处生效

葛聪慧

1. 定义变量

变量写在选择器里，通常放在 :root，全局都能用。必须以 -- 开头。

:root {
  --Ge-primary: #4f46e5;
  --Ge-radius: 14px;
}

2. 使用变量

在属性值中用 var() 读取变量，可设置默认值 var(变量, 默认值)。

color: var(--Ge-primary);
border-radius: var(--Ge-radius);
width: var(--Ge-w, 200px);

3. 局部覆盖

子元素可重新赋值变量，只影响自身及后代，实现主题切换。

.Ge_theme-green {
  --Ge-primary: #059669;
}

实时效果（点击上方按钮切换主题）

这根渐变条、卡片顶边、标题颜色都来自 var(--Ge-primary)

制作：葛聪慧 · 本页颜色、圆角、间距、阴影全部由 CSS 变量统一管理。 切换主题时只需改变量的值，无需逐条修改每条样式规则——这正是 CSS 变量的意义： 一处定义，多处复用，整体换肤。
