Font Awesome · 网页字体图标

图标被铸进字体文件，用 class 选字形、用码点取字符，像文字一样放大变色

葛聪慧

工作原理

1. @font-face 引入字体

样式表链接本地字体文件 cdn/fontawesome/webfonts/fa-solid-900.woff2、fa-regular-400、fa-brands-400，图标本质上是字体里的“字”。

2. 码点映射字形

每个 class 对应一个 Unicode 码点，:before 伪元素把码点字符画出来，字体文件负责把它渲染成图案。

.fa-house{--fa:"\f015"}
.fa-solid:before{content:var(--fa)}

3. 文字特性全继承

font-size 控制大小、color 控制颜色、text-shadow、transform 都有效，还能用 fa-spin 旋转动画。

字体特性：像文字一样控制

点击按钮，直接改变字号 / 颜色 / 动画

这些图标全是字体字符，所以 font-size、color、transform 对它们天然生效，无需切换图片。

写法与本地文件

1. 引入本地样式表

CDN 文件已下载到本目录 cdn/ 下，字体在 cdn/fontawesome/webfonts/。

<link rel="stylesheet" href="cdn/fontawesome/css/all.min.css">

2. 标签 + class

用 <i> 占位，前缀区分实心、线性、品牌三种字重。

<i class="fa-solid fa-house"></i>
<i class="fa-regular fa-heart"></i>
<i class="fa-brands fa-github"></i>
<i class="fa-solid fa-gear fa-spin"></i>

3. 渲染过程

浏览器加载字体 → 按码点找字形 → 用文字样式上色渲染，所以矢量放大不模糊。

.fa{font-family:"Font Awesome 6 Free"}
.fa-2x{font-size:2em}
.fa-spin{animation:fa-spin 2s infinite}
