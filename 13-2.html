Lucide · SVG 矢量图标

每个图标都是一个独立的 <svg> 元素：24×24 视图、stroke 描边、currentColor 取色

葛聪慧

工作原理

1. 占位符渲染

页面写 <i data-lucide="heart"> 占位，引入 cdn/lucide/lucide.min.js 后调用 createIcons()，把它替换成真正的 svg 元素。

2. 描边继承颜色

svg 用 stroke="currentColor" 画线，线条颜色跟随父级文字 color；stroke-width 控制粗细，全是标准 SVG 属性。

<svg stroke="currentColor" stroke-width="2"
  fill="none" viewBox="0 0 24 24">

3. 矢量无级缩放

图形由路径 path 描述而非像素，width/height 随便改都不会糊；还能用 CSS 改描边、加动画。

写法与生成的 SVG

1. 引入本地脚本

脚本已下载到 cdn/lucide/lucide.min.js，图标库自带1700多个 svg 路径数据。

<script src="cdn/lucide/lucide.min.js"></script>
<script>lucide.createIcons();</script>

2. 占位符写法

data-lucide 属性写图标名，渲染后被替换成 svg，同时带上 lucide lucide-heart 类名。

<i data-lucide="heart"></i>
<i class="Ge_item_icon" data-lucide="search"></i>

3. 渲染出的 SVG 源码

图标就是普通 HTML 里的 svg 标签，路径数据内嵌，不依赖字体文件。

<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M19 14c1.49-1.46 3-3.21 3-5.5A5.5 5.5 0 0 0 16.5 3c-1.76 0-3 .5-4.5 2-1.5-1.5-2.74-2-4.5-2A5.5 5.5 0 0 0 2 8.5c0 2.3 1.5 4.05 3 5.5l7 7Z"/></svg>
