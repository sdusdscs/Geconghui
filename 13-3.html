iconfont 字体图标 · 底部导航

position: fixed + width: 100% 固定全屏，flex 让 4 个导航项自适应各占 25%

葛聪慧

实现要点

1. iconfont 字体图标

引入 font/iconfont.css，图标通过 font-family: iconfont + :before 码点渲染，导航用 icon-zhuye、icon-faxian、icon-tongzhi、icon-gouwuche。

<link rel="stylesheet" href="font/iconfont.css">
<i class="iconfont icon-zhuye"></i>

2. 固定 + 全屏宽度

导航用 position: fixed 脱离文档流钉在视口底部，left: 0; right: 0; width: 100% 占满整个屏幕宽度，滚动页面不移动。

position: fixed;
left: 0; right: 0; bottom: 0;
width: 100%;

3. 移动端自适应

viewport 适配手机屏幕；导航是 flex 容器，每项 flex: 1 1 25%，任何屏宽都自动均分为 4 项，不写死像素。

display: flex;
.Ge_tab { flex: 1 1 25%; }

导航项：数字徽章 + 右上角红点

点击底部导航切换（点击后该项红点消失）

每个导航项 = 图标 + 数字徽章（图标右上角的红色胶囊）+ 红点（导航项右上角）。向下滚动，导航始终固定在屏幕底部。

徽章：绝对定位在图标右上角，白圈描边压住图标Ge_badge
红点：定位在导航项右上角，提示未读消息Ge_dot
数字超出 99 显示为 99+，胶囊宽度自适应99+
字体图标随 color 继承颜色，选中态变主题色currentColor
整条导航占满屏幕宽度，左右不留白width:100%
iOS 底部安全区用 env(safe-area-inset-bottom) 适配safe-area

关键代码

1. 导航结构（4 项）

<nav class="Ge_tabbar">
  <a class="Ge_tab Ge_active">
    <span class="Ge_icon_box">
      <i class="iconfont icon-zhuye"></i>
      <b class="Ge_badge">8</b>
    </span>
    <span class="Ge_tab_text">首页</span>
    <i class="Ge_dot"></i>
  </a>
  …共4项
</nav>

2. 徽章与红点

.Ge_badge { position: absolute;
  top: -7px; right: -17px;
  background: #ef4444; }
.Ge_dot { position: absolute;
  top: 5px; right: 6px;
  width: 8px; height: 8px; }

3. 字体图标上色

导航文字是什么颜色，图标就跟着变；选中项只需改 color。

.Ge_tab { color: #6b7280; }
.Ge_tab.Ge_active { color: #6d28d9; }
.Ge_tab .iconfont { font-size: 24px; }
