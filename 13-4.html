SVG symbol + use · 底部导航

同一个 iconfont 项目，改成 svg 矢量：symbol 定义 + use 引用，颜色用 fill: currentColor 继承

葛聪慧

实现要点

1. SVG 精灵复用

把 font/iconfont.js 里的4个 symbol（zhuye/faxian/tongzhi/gouwuche）放进页面隐藏 svg，导航用 use 引用，一份路径多处复用。

<svg style="position:absolute;width:0;height:0">
  <symbol id="icon-zhuye" viewBox="0 0 1024 1024">…
</svg>
<svg class="Ge_tab_icon"><use href="#icon-zhuye"></use></svg>

2. 固定 + 全屏宽度

与字体方案相同：position: fixed 钉在视口底部，left: 0; right: 0; width: 100% 占满整屏宽度，滚动不跟随。

position: fixed;
left: 0; right: 0; bottom: 0;
width: 100%;

3. 自适应与上色

viewport 适配手机屏，导航 flex 每项 flex: 1 1 25% 自动均分；svg 没有 fill 属性时继承 fill: currentColor，跟随文字颜色。

display: flex;
.Ge_tab { flex: 1 1 25%; }
.Ge_tab_icon { fill: currentColor; }

导航项：数字徽章 + 右上角红点

点击底部导航切换（点击后该项红点消失）

每个导航项 = svg 图标 + 数字徽章（图标右上角红色胶囊）+ 红点（导航项右上角）。向下滚动，导航始终固定在屏幕底部。

徽章：绝对定位在图标右上角，白圈描边压住图标Ge_badge
红点：定位在导航项右上角，提示未读消息Ge_dot
数字超过 99 显示 99+，胶囊宽度自适应内容99+
svg 用 fill: currentColor 继承文字颜色，选中变主题色currentColor
矢量路径无级缩放，任何屏宽都不模糊viewBox
整条导航占满屏幕宽度，左右不留白width:100%

关键代码

1. 导航结构（4 项）

<nav class="Ge_tabbar">
  <a class="Ge_tab Ge_active">
    <span class="Ge_icon_box">
      <svg class="Ge_tab_icon" viewBox="0 0 1024 1024">
        <use href="#icon-zhuye"></use>
      </svg>
      <b class="Ge_badge">8</b>
    </span>
    <span class="Ge_tab_text">首页</span>
    <i class="Ge_dot"></i>
  </a>
  …共4项
</nav>

2. 徽章与红点

.Ge_badge { position: absolute;
  top: -7px; right: -17px;
  background: #ef4444; }
.Ge_dot { position: absolute;
  top: 5px; right: 6px;
  width: 8px; height: 8px; }

3. 与字体图标的区别

不再需要 @font-face 和码点，图标就是页面里的 svg 元素，可直接改路径、加变形动画。

.Ge_tab_icon { width: 24px; height: 24px;
  fill: currentColor; }
.Ge_tab.Ge_active { color: #ea580c; }
