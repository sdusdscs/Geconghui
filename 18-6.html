一、智能客服系统处理流程图
flowchart TD
    A[用户发起咨询] --> B[会话接入]
    B --> C{是否为常见问题}
    C -->|是| D[命中FAQ知识库]
    C -->|否| E{意图识别}
    E -->|售前咨询| F[商品推荐引擎]
    E -->|售后问题| G[工单系统]
    E -->|其他/模糊| H[人工客服转接]
    D --> I{答案置信度是否达标}

    I -->|不达标| K[RAG检索增强生成]
    F --> L[生成个性化回复]
    G --> M[创建工单并跟踪]
    J --> Z[对话结束]

二、智能客服系统数据库ER图
erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    SESSION ||--o{ INTENT : "识别"
    USER ||--o{ FEEDBACK : "提交"
    MESSAGE ||--o| FEEDBACK : "评价"
    KNOWLEDGE ||--o{ ANSWER : "生成"
    INTENT ||--o{ KNOWLEDGE : "检索"
    MESSAGE }o--|| KNOWLEDGE : "匹配引用"

    USER {
        int user_id PK
        string nickname
        string phone
        datetime created_at
    }
    SESSION {
        int session_id PK
        int user_id FK
        string channel
        datetime start_time
        datetime end_time
    }
    MESSAGE {
        int message_id PK
        int session_id FK
        string role
        string content
        datetime send_time
    }
    FEEDBACK {
        int feedback_id PK
        int message_id FK
        int user_id FK
        int rating
        string comment
    }
    INTENT {
        int intent_id PK
        string name
        string description
    }
    KNOWLEDGE {
        int knowledge_id PK
        string title
        string category
        string content
        int intent_id FK
    }
    ANSWER {
        int answer_id PK
        int knowledge_id FK
        string text
        float confidence
    }
